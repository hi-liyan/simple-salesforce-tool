LAN Drop 已开启

把手机、平板、电脑里的文件直接传到当前桌面工具

保持这个页面打开，选择一个或多个文件后点击上传。文件会被保存到桌面应用本地，并在应用的工具页中实时出现，可继续预览、筛选和删除。

1. 选择文件 支持图片、文本、日志、JSON、压缩包等常见文件，也支持多文件批量上传。
2. 多端自适应 手机、平板和桌面浏览器都会自动适配，不需要安装额外 App。
3. 上传即入库 成功上传后，桌面端工具页会自动刷新，方便马上预览和管理。

添加文件

可以点按选择，也可以直接把文件拖进下方区域。上传时会保留原始文件名。

使用建议

为了获得更稳定的体验，请尽量确保发送设备和桌面应用处在同一 Wi-Fi 或同一网段内。

上传完成后去哪看？ 回到桌面应用的“局域网接收文件”工具页，右侧会显示最新文件并支持直接预览。
如果页面打不开 可以让桌面端重新开关一次接收服务，或者确认当前网络没有隔离访客设备。
如果文件很大 建议分批上传。对于超大图片或压缩包，桌面端会保留文件但可能不直接内嵌预览。
