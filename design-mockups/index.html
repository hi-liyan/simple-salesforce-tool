这一轮设计稿以“深色玻璃态 + 冷色霓虹 + 低对比分层”为核心，围绕当前 Tauri 桌面应用的工作流重组主工作台信息层级， 让 Query、Terminal、Tools、Settings 与独立窗口拥有统一的视觉语言。

设计原则

保留桌面生产力工具的操作效率，不做“只有概念感”的空壳 Web3 UI。重点通过层级重组、光效控制和玻璃表面，让复杂工作流更清楚。

页面设计稿

先从 Query 主工作台看整体风格，再依次检查 Terminal、Tools、Settings 与两个独立窗口。

Dashboard · Query

默认首页，聚焦数据源树、查询编辑、结果矩阵与右侧对象情报栏。

Dashboard · Terminal

沉浸式终端舞台，配合命令库、会话状态与脚本情报侧栏。

Dashboard · Tools

以 Tool Capsules 方式承载 JSON Formatter、Text Diff、JSON Diff 的入口与近期活跃度。

Dashboard · Settings

系统控制台式设置页，左侧分组导航，中间配置面板，右侧风险与帮助情报区。

Auth Window

聚焦式授权窗口，采用钱包连接弹窗的视觉语言强化 OAuth 入口。

Field Meta Window

窄窗数据仪表板化，把字段元数据从纯文本列表升级为结构化 Data Sheet。
